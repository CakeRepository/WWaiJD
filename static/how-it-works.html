How it Works

The Mission

To help people explore the Bible using modern technology.

The Technology

We use Gemma 3 (4B) running locally via Ollama.

We use a technique called RAG (Retrieval-Augmented Generation). Simply put: We search the Bible for verses relevant to your question, then ask the AI to answer using only those verses.

The Bible Version

We use the World English Bible (WEB), which is in the public domain.

Limitations

AI can hallucinate. It is not a replacement for a pastor or personal study.
